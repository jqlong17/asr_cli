# asr_cli Spec Index

This directory records implementation specs for code-level changes to the local AI CLI toolbox. Any change that affects tool architecture, model packaging, runtime boundaries, public CLI/server behavior, or model installation must have a spec before implementation.

## Naming

Use:

```text
NNN-YYYYMMDD-HHMMSS-short-topic.md
```

- `NNN`: three-digit increasing number.
- `YYYYMMDD-HHMMSS`: local creation time.
- `short-topic`: lowercase English slug.

## Required Sections

Each spec must include:

1. Background
2. Goals
3. Non-Goals
4. CLI / Server Contract
5. Implementation Plan
6. Acceptance Checks
7. Review Notes
